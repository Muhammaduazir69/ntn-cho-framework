What ntn-cho-framework does

ntn-cho is an ns-3 module for conditional handover (CHO) in LEO non-terrestrial networks that estimates each candidate satellite's time to exit from propagated orbits and conditions the handover decision on it. It also implements the 3GPP TS 38.331 CondEvent A3, D1, T1 and Rel-18 D2 triggers, plus elevation and timing-advance mechanisms from TR 38.821, each evaluated against live geometry.

Accompanying studyConditional Handover in LEO Satellite Networks Under Ephemeris Error: Handover-Rate Analysis and Exit-Error Propagation. Code and data are in this repository.

What it models

A LEO cell moves away from its users, so the neighbor that looks best now may be about to set. ntn-cho estimates time to exit (TTE), how long a candidate remains serviceable, by a coarse forward scan over the propagated orbit followed by a binary search for the beam-exit instant. With a line-of-sight probability table it also returns the expected usable time to exit, and it propagates an injected RTN ephemeris error into a first-order sigma of the exit time. The Rel-17 CHO state machine runs from idle through preparation, condition monitoring and execution to completion. Its trigger classes are 3GPP TS 38.331 CondEvent A3, D1 on a fixed reference location, T1 on an absolute window, Rel-18 D2 on a moving ephemeris reference (Section 5.5.4.15a), elevation and timing advance as studied in 3GPP TR 38.821, TTE-aware selection, Rel-19 conditional LTM and trajectory-predictive CHO, with optional RACH-less execution from timing-advance pre-compensation.

UEs move according to the 3GPP TR 38.811 Section 6.1.1.1 classes (handheld, pedestrian, vehicular, HST, maritime, aviation, fixed IoT) in ECEF, and a measurement model gives TR 38.811 RSRP, SINR and signed Doppler. In the real-stack examples the algorithm decides on the measured SINR of an NR NTN cell. CHO is modeled at the decision and timing level: there is no over-the-air conditional reconfiguration PDU, and the RACH interruption is priced as slant round trip plus processing. Trigger-decided and fallback-decided handovers are counted separately, so the CHO layer is not credited with a cell change the radio would have made anyway.

Install

Every module ships in the ready-built container image of the toolkit (version 3.0.1):

docker pull uzairdocker69/ns3-ntn-toolkit:latest
docker run --rm -it uzairdocker69/ns3-ntn-toolkit:latest bash

To build from source, clone ns3-ntn-toolkit, which vendors this module under contrib/, or follow the README of this repository (branch ntn-cho-v4).
